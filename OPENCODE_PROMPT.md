## 1. Game concept and tone

- Silly, wholesome, slapstick humour. Cartoon violence only: darts make people **fall asleep face-first and snore**, nets tangle geese, water pops balloons, pillows bonk an alarm clock. No blood, no death, no mean-spirited jokes.
- You play an over-serious secret agent in a black suit and gloves (`fp_arms.glb`). Each mission is a ridiculous "job" briefed with a dead-serious dossier.
- **6 levels, played in order.** A level unlocks only when the previous one is completed. After level 6 the game is **finished**: an ending + credits sequence plays, every level shows as completed, and levels stay replayable from the menu.
- All dialogue is **on-screen text** (speech bubbles over NPCs + subtitle bar). There is no voice acting.

## 2. Tech stack (use exactly this)

- **Vite + TypeScript + three.js `0.160.0`** (the assets were tested on this version). Use `three/addons/...` imports: `GLTFLoader`, `SkeletonUtils`, `Octree`, `Capsule`, `RoomEnvironment`, `BufferGeometryUtils`.
- **Collision/physics:** use the three.js **Octree + Capsule** approach from the official `games_fps` example, no physics engine. Build each level's Octree from a hidden set of **simple box collision meshes**, not from the detailed render meshes. Projectiles use simple ray/sphere tests against the Octree plus sphere-vs-capsule tests against NPCs.
- UI is **HTML/CSS overlays** on top of the canvas (no UI framework required; vanilla TS modules are fine).
- Audio is **Web Audio API**: `AudioContext` plus `THREE.AudioListener` / `THREE.PositionalAudio` for 3D sounds.
- No backend. Progress and settings go in `localStorage`, with every read and write wrapped in try/catch.

## 3. Asset reference (everything is in `public/assets/`)

### Global conventions (also in `manifest.json → conventions`)
- Units are **metres**, **+Y up**. **Models face +Z**: rotate `Math.PI` around Y to face −Z. The origin is the base centre at y=0 unless noted.
- **Materials** are vertex-coloured `MeshStandardMaterial`. A material whose name starts with `tint_` (`tint_skin`, `tint_hair`, `tint_shirt`, `tint_pants`, `tint_balloon`, `tint_wrap`, `tint_hat`) is single-colour. To recolour it: clone the material, set `vertexColors = false`, then `color.set(hex)`.
- **Accessories** are named `acc_*`. A multi-material accessory loads as a **Group `acc_x` with child meshes**, so always toggle visibility on the **whole subtree** (`obj.traverse(c => c.visible = v)`). This is a real gotcha: hiding by name alone leaves children hidden.
- **Characters are skinned.** Clone them with `SkeletonUtils.clone()`. Each `.glb` has its own animation clips. Use one `AnimationMixer` per instance and crossfade (0.2 s) between clips. One-shot clips (use `LoopOnce` + `clampWhenFinished`): `Fall`, `Jump`, `Point`, `Honk`, `Swat`, `Startled`, `Bite`, `Pop`, `Stomp`, `Hurt`, `Defeated`, and the alarm clock's `Hop`. Everything else loops (the balloon dog's `Hop` is a loop).
- **Sockets / markers** are empty nodes. Attach props to them with `node.add(prop)`.
- **Weapons:** the origin is the right-hand grip and the barrel points **−Z**. Marker `muzzle` is the projectile spawn point; marker `grip_L` is where the left hand goes.

## 4. Game flow and screens

1. **Boot / loading:** a dark screen with `logo.svg` and a progress bar. Preload only the menu assets here; preload each level's assets when it is selected, with its own loading bar.
2. **Title:** `menu_background.png` full-bleed (cover, slow Ken-Burns zoom), the logo, "CLICK TO START" pulsing. The click unlocks audio and starts `music_menu`.
3. **Main menu:** **Play** (jumps to the next unfinished level), **Missions** (level select), **Settings**, **Credits**. Menu items play `ui_hover` / `ui_click`.
4. **Level select:** 6 cards in a grid (3×2 on desktop, 1 column on narrow screens) using the `thumb_*` renders. Each card shows the number, title, location, best time and 0–3 stars. Locked cards are greyscale with the `lock` icon; clicking one plays `ui_locked` and shakes the card. Completed cards show the `check` icon.
5. **Briefing (dossier):** a manila-folder style panel showing the target portrait, mission name, a deadpan description, objectives, the level's controls, and the "Equipment issued" weapon. Buttons: **Accept Mission** (`ui_confirm`) / Back.
6. **Gameplay** with the HUD. **Esc** opens Pause: Resume, Restart, Settings, Quit to Missions. Releasing pointer lock also pauses.
7. **Mission Complete:** slow-mo for 1 s, `mission_complete` + `confetti`, a rubber-stamp animation "MISSION ACCOMPLISHED", a punchline caption, stats (time, accuracy, level-specific stat), stars, and buttons Next Mission / Replay / Missions.
8. **Mission Failed:** `mission_failed` (sad trombone), a red stamp "MISSION FAILED", a funny fail caption for the specific failure, and buttons Retry (instant, no reload) / Missions.
9. **Ending (after L6 is first completed):** a "ALL MISSIONS COMPLETE" stamp, then a credits roll over `menu_background` with `music_menu` and career stats ("Garys darted: X (Y were not Gary)", "Bowls of soup consumed", "Geese netted", "Balloons popped", "Snooze buttons pressed", "Total time"), ending with **"You're done. Go outside."** Return to the menu, where a "Game Complete" ribbon is now shown. All levels stay replayable.

**Save data** (`localStorage` key `tp_save_v1`): `{ unlocked: number, levels: { [id]: { done, stars, bestTime } }, stats: {...}, settings: {...} }`.

**Settings:** mouse sensitivity, invert Y, FOV (70–100, default 80), master/music/SFX volume, quality (Low/Medium/High: pixel ratio 1/1.25/1.5 cap, shadow map 512/1024/2048, shadows on/off), "show subtitles" toggle.

## 5. Player and controls (shared by all levels)

- **Input:** pointer lock. **WASD** move, **mouse** look, **Space** jump, **Shift** sprint, **Ctrl/C** crouch (crouch while sprinting = **slide** for 0.8 s), **E** interact/tackle, **LMB** fire, **R** reload, **G** throw (L3 bread), **Esc** pause. Show a key-hint strip in each briefing.
- **Controller** (Octree + Capsule): capsule radius 0.35, height 1.7, eye at 1.6. Walk 4.5 m/s, sprint 7.5 m/s, crouch 2.2 m/s. Gravity 25, jump 8.5. Coyote time 0.12 s, jump buffer 0.12 s. Accelerate on the ground, with limited air control.
- **Parkour (important for L2):** **auto-mantle**: when moving into a ledge whose top is 0.5–1.4 m above the feet while jumping or sprinting, lerp up and over it in 0.35 s with a small camera dip. **Vault** low obstacles (<1.0 m) while sprinting. Slide under clotheslines and pipes.
- **Camera feel:** head-bob while moving, landing dip, FOV +6 while sprinting, a light screen-shake utility, weapon sway (lagged mouse delta), recoil kick per weapon.
- **Viewmodel:** render the weapon and arms with a separate camera/scene layer drawn after the world, with depth cleared, so they never clip into walls. FOV 60.
- **Health:** 5 hearts (only used in L3 and L6). Damage gives a red vignette, a camera kick and 1 s of invulnerability.
- **Interact prompt:** a centre-screen "[E] Tackle" / "[E] Unplug router" style prompt when within 2 m and looking at the target.

## 6. The six missions (implement exactly; tune numbers if needed)

### L1: "SPOT THE GARY" (The Office). Weapon: Dart Pistol. Music: `music_office`
- **Briefing:** "Target: GARY GORDON, Regional Manager. He has scheduled a 4-hour meeting about meetings. Neutralise (nap) him. Complication: today is GARY APPRECIATION DAY and the entire staff has dressed as Gary." Show `portrait_gary` + `lineup_garys`.
- **Map:** an open-plan office about 30×22 m, ceiling 3.2 m. Rows of `desk_setup` + `office_chair`, cubicle walls, a break area (water cooler, vending machine, printer), a whiteboard, the `banner_happy_gary_day` banner, a `poster_gary_employee` on a wall, plants, ceiling lights (use the emissive look; don't add a real light per fixture). Two `door`s.
- **NPCs:** 24 office workers, **all in the Gary costume**, with random skin tones (tint `tint_skin` from a natural range), random height 0.95–1.05, some with `acc_party_hat`. Behaviours: SitTyping at desks, Talk in groups of 2–3, Sip at the cooler, Walk between waypoints, Idle.
- **Real Gary:** one random NPC (a different one each run). He has the **"tells"**: `acc_mustache` (straight, real) **plus** `acc_tie_stain`, `acc_watch_R`, `acc_pen_ear`, carries `acc_mug`, and periodically plays `Hum` with positional `gary_hum` audio (audible within ~8 m). He wanders: cooler (Sip) → whiteboard → his desk → printer.
- **Decoys:** each decoy gets `acc_mustache_crooked` (fake) **or** the straight one (30% chance, so the mustache alone isn't enough), plus a random 0–2 of the other tells. **Guarantee no decoy has all of: straight mustache, stain, right-hand watch, pen.** Decoys never Hum.
- **Clue system:** the dossier sidebar (HUD, Tab to expand) lists 5 clue slots shown as `clue_unknown`. Clue 1 (mustache) is known at the start. Unlock the others by: **eavesdropping** (stand within 3 m of a Talk group for 3 s → subtitle gossip like *"Gary only wears his watch on his RIGHT wrist. Like a maniac."*), a **sticky note** on a desk (look at it + E: *"Gary — your pen is behind your ear AGAIN"*), the **whiteboard** (*"Whoever keeps spilling coffee on their tie: we know it's you, Gary"*), and the **hum** (hearing it within 6 m unlocks *"Gary hums when he's happy"*). Each unlock plays `clue_found` and flips the icon.
- **Shooting:** the dart flies at 40 m/s with slight gravity, 6 darts, reload 1.5 s. Hitting any Gary plays `Fall` → `Sleep` + `snore` loop + floating "Zzz".
  - **Wrong Gary:** `wrong_target` + `crowd_gasp`, nearby NPCs `Panic` briefly then resume, and the HUD **"HR complaints"** counter goes up. 3 complaints = fail: *"You darted three innocent Garys. HR would like a word."*
  - **Real Gary:** he faceplants (ideally onto a desk or the cake), the office cheers (`Celebrate` for 2 s), then Mission Complete: *"Target napping. The meeting about meetings has been postponed indefinitely."*
- **Stars:** ★ complete, ★ 0 complaints, ★ under 3:00.

### L2: "COLD FEET" (Rooftops). Unarmed. Music: `music_chase`
- **Briefing:** "Client: the Bride. Target: the GROOM, who has sprinted off the rooftop wedding at the words 'you may now'. Return him to the altar. You have the ring. He has… cardio."
- **Map:** a linear route over **7–8 rooftops** of different heights (box buildings, 20–60 m tall, `building_facade` walls, `roof_gravel` tops, `building_trim` parapets), with a city backdrop of distant boxes and a warm sunset gradient sky + fog. Gaps of 2–4 m to jump, a `plank` bridge over a 3 m gap, `ac_unit`s / `crate`s / `chimney`s to vault, `clothesline`s to slide under, a `rooftop_door` hut to mantle onto, a `water_tower` at the finale, a `billboard` with `billboard_cold_feet`, `antenna` beacons blinking. Place 4 checkpoints (glowing ground ring).
- **Start:** the wedding on roof 1: `wedding_arch`, rows of `wedding_chair`s, the bride (Idle → Point), and guests (office_worker with normal hair, varied shirt/pants tints, Wave/Talk). The groom (`acc_sweat` on) yells *"I'M NOT READY!"* and runs (`RunLookBack`).
- **Groom AI:** follows a hand-placed spline/waypoint path with jumps (play `Jump` at gaps and lerp an arc). **Rubber-band** his speed to stay 6–20 m ahead: he slows when you're far and speeds up when you're close, until the final roof, where a dead end at the water tower **corners** him (`Panic`). Barks every 6–10 s: *"I've got a dentist appointment!"*, *"Is it too late to become a monk?!"*, *"My mom said I could have a sleepover!"*, *"I left the oven on! I don't own an oven!"*

## 7. AI, animation and feel

- Use a generic `Npc` class: mixer + state machine (`idle/walk/run/act/react/disabled`), crossfades, steering that moves toward a waypoint and turns smoothly (yaw slerp), simple avoidance (separation from other NPCs + raycast probes against the Octree), and a feet-on-ground raycast. Animation speed should scale with movement speed so feet don't slide (Walk clip ≈ 1.4 m/s, Run ≈ 4.2 m/s, goose Walk ≈ 0.8 m/s).
- Speech bubbles: CSS elements projected to screen over NPC heads (`socket_head_top`), fading after 2.5 s. Subtitles at the bottom for the important lines.
- Juice: hit-markers on the crosshair, screen shake, particle bursts (confetti, water splashes, "Zzz", sweat drops, feathers) via a small pooled `THREE.Points`/instanced-quad particle system, slow-mo on mission complete, and a camera punch on tackle.

## 8. Rendering and performance (target: solid 60 fps on a laptop iGPU)

- `WebGLRenderer({ antialias: true, powerPreference: 'high-performance' })`, `outputColorSpace = SRGBColorSpace`, `toneMapping = ACESFilmicToneMapping`, exposure about 1.0. Use `RoomEnvironment` + `PMREMGenerator` as `scene.environment` (intensity ~0.35) for nice speculars.
- Lighting per level: one shadow-casting `DirectionalLight` whose shadow camera **follows the player** (tight frustum ~30 m), plus a `HemisphereLight`. Indoor levels add a few non-shadow point lights. Use `PCFSoftShadowMap` on High, `PCFShadowMap` on Medium, no shadows on Low.
- Add per-level fog and gradient sky colours (the gradient-sky helper is in `render_shots.html`).
- Pixel ratio = `min(devicePixelRatio, qualityCap)`.
- **Draw calls:** static props that repeat (desks, chairs, trees, roof trims, fence segments) → `InstancedMesh` per sub-mesh/material, or merge all static level geometry per material with `BufferGeometryUtils.mergeGeometries` at level build time. Share materials and textures; never clone a material unless tinting.
- Skinned characters: update mixers only for NPCs within 40 m or on screen. Freeze/skip animation updates for far NPCs.
- Pool projectiles and particles; no per-frame allocations in hot loops.
- On level unload, dispose geometries, materials and textures that aren't shared, and stop audio sources.
- Budget per level: < 300 draw calls, < 700k triangles, < 150 MB GPU memory.
- Add an FPS/draw-call debug overlay toggled with **F3**.

## 9. UI / UX style

- **Fonts:** Google Fonts **"Bangers"** for headings/stamps and **"Nunito"** (700/900) for body text. Use a `<link>` in `index.html`.
- **Palette:** ink `#1b1b1f`, orange `#ff922b`, yellow `#ffd43b`, pink `#ff4f6d`, teal `#19b3a6`, panel navy `#2b2d42`, paper `#f4f1ea`. Chunky 4 px ink outlines, offset drop shadows, slight rotations on stamps and cards, and bouncy CSS transitions (cubic-bezier overshoot).
- **HUD:** crosshair (`icons/crosshair.svg`), top-left mission objective text + timer, top-right level-specific widget (HR complaints / groom distance meter / thief arrow / soup bowls + detection meter / cake HP bar / boss snooze levels), bottom-right ammo with the weapon's ammo icon, bottom-left hearts when applicable, and an interaction prompt in the centre.
- Must be usable at 1280×720 up to 4K. Show a friendly "Desktop + mouse & keyboard required" notice on touch-only devices instead of a broken game.
- Accessibility: subtitles on by default, a colour-blind-safe detection meter (also uses shape/size), and a pause on blur.
